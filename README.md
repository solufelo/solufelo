## 🧑‍🚀 Who is Captain Solo?

I'm **Solomon Olufelo**, a Brampton-based Creative Technologist and Computer Science student at Wilfrid Laurier University. Before code paid the bills, audio and video did. I've delivered over **1,400+ independent freelance orders** maintaining a 4.8/5-star rating, and now I merge that creative multimedia background with hard systems programming.

I geek out over system architecture, performance optimization, and immersive web experiences. I don't just build websites; I engineer interactive platforms.

## 💻 Tech Stack & Interests

My toolbelt is split between high-level web immersion and low-level systems logic:

### 🕸️ The Web Immersion Stack (This Repo)
- **Frontend Core**: React 19, Vite, Tailwind CSS v4
- **3D & Graphics**: Three.js, React Three Fiber, Drei (Liquid Glass themes, interactive planets)
- **Animation**: GSAP (ScrollTrigger, Observer) for complex scroll transitions
- **Backend/Services**: Supabase (Auth), EmailJS, Stripe, Python/cPanel API integrations

### ⚙️ The Systems & Automation Stack
- **Languages**: `C++17/20`, `Python`, `SQL`, `GLSL`
- **Engines & Graphics**: OpenGL 3.3, SFML, SDL2
- **Automation**: Playwright (for scraping/automation), SQLite
- **Deployment**: Docker, CMake, WebAssembly (Emscripten), Linux VPS / cPanel administration

## 🛠️ Local Development

If you want to spin up the web platform locally:

```bash
# Clone the repository
git clone https://github.com/solufelo/captainsoloHQ.git
cd captainsoloHQ

# Install dependencies (requires Node.js)
npm install

# Start the Vite development server
npm run dev
```
